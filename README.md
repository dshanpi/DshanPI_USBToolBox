# DshanPI USBToolBox

DshanPI USBToolBox 官方发布与下载仓库。

本仓库仅用于提供 DshanPI USBToolBox 的正式版本安装包，不公开应用程序源代码。

## 下载

**Windows x64：下载 [v1.0.10 安装包](https://github.com/dshanpi/DshanPI_USBToolBox/releases/tag/v1.0.10)。**

- [EXE 安装包（推荐）](https://github.com/dshanpi/DshanPI_USBToolBox/releases/download/v1.0.10/DshanPI.USBToolBox_1.0.10_x64-setup.exe)
- [MSI 安装包](https://github.com/dshanpi/DshanPI_USBToolBox/releases/download/v1.0.10/DshanPI.USBToolBox_1.0.10_x64_en-US.msi)
- [SHA-256 校验文件](https://github.com/dshanpi/DshanPI_USBToolBox/releases/download/v1.0.10/SHA256SUMS.txt)

EXE 和 MSI 任选其一。安装后可在软件内安装配套驱动，按 **F1** 在浏览器打开内置图文使用指南。

v1.0.10 目前仅提供 Windows x64 手动安装包，暂未提供该版本的 macOS 和 Linux 安装包。自动更新通道和 GitHub `Latest` 标记暂保留在 v1.0.9；下载 Windows 新版请使用上面的 v1.0.10 链接。

其他已发布安装包见 [全部 Releases](https://github.com/dshanpi/DshanPI_USBToolBox/releases)。请仅从本仓库的 Release 附件下载软件，并阅读对应版本的签名与兼容性说明。
