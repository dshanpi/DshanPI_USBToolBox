# DshanPI USBToolBox 功能说明文档

> 版本：v1.0.0
> 适用对象：使用本软件进行串口调试、Modbus 分析、以及通过 CH347 桥接芯片进行 I²C / SPI / SPI 屏幕调试的工程师。

---

## 1. 软件概述

**DshanPI USBToolBox** 是一款跨平台桌面应用，基于 **Tauri 2.x**（Rust 后端 + React 19 / TypeScript 前端）构建，主要面向嵌入式开发中的**总线调试**与**外设点屏**场景。

软件采用左侧工具栏 + 右侧工具面板的布局，所有工具页面常驻挂载、切换时仅做显隐动画，因此在工具间来回切换不会丢失各自的连接状态与编辑内容。

> **关于本文档范围**
> 当前 v1.0.0 构建在侧边栏中**实际开放给用户**的工具共 **5 个**（见第 3 章）。
> 源码中还包含一整套面向全志（Allwinner / Sunxi）芯片的固件烧写与调试工具，但它们在本构建里**未挂载到导航**，普通用户无法打开，仅作为后续/隐藏功能存在（见第 6 章）。

### 技术与运行环境

| 项目 | 说明 |
| --- | --- |
| 前端 | React 19 + TypeScript 5.7 |
| 后端 | Rust + Tokio 异步运行时（Tauri 命令） |
| 主题 | 亮 / 暗双主题（默认暗色 Catppuccin Mocha） |

| 硬件桥接 | CH347 USB 桥接芯片（I²C / SPI / SPI 屏幕工具使用） |

## 2. 通用概念

### 2.1 CH347 设备桥接

I²C 工具、SPI 工具、SPI 点屏工具三者通过 **CH347 USB 转接芯片**与目标总线通信，三个工具**共享同一个 CH347 设备状态单例**——即在任一工具里打开的设备，在其它工具中也是同一个连接。

- 通过 **扫描（↻）** 枚举 CH347 设备，下拉框选择后点 **打开 / 关闭**。
- 软件内置**热插拔监视**：设备打开后每隔约 1.5 秒检测一次，若 USB 被拔出会自动断开并在界面提示，避免后续操作报"句柄无效"。

### 2.2 日志与预设

各工具普遍提供：

- **日志控制台**：带时间戳、收发方向、按级别（info / success / error）着色，支持鼠标选中复制。
- **预设系统**：可将常用的命令序列 / 初始化序列保存为预设，持久化到本地（localStorage），下次进入仍在；内置预设不可删除，用户预设可另存 / 删除。

## 3. 核心工具（当前版本开放）

侧边栏中的工具按以下顺序排列，启动后默认进入**串口工具**。

### 3.1 串口工具（Serial Tool）

> 串口调试工具，对标 MobaXterm / 串口助手。

通过 Rust `serialport` 后端连接主机串口，每个端口独立读取线程。

**主要功能：**

- **端口配置**：端口选择、波特率、数据位、停止位、校验（无 / 奇 / 偶）、流控（无 / RTS-CTS / XON-XOFF）；支持刷新与自动扫描端口。
- **终端式输入**：可像 PuTTY 一样直接在监视区键入字符发送。
- **显示增强**：收发时间戳与方向标记（发→ / 收←）、整屏 HEX 显示切换、ANSI 转义序列剥离（兼容跨包分段）。
- **右键菜单**：复制 / 粘贴 / 保存日志 / 字体放大缩小。
- **自定义发送**：文本输入框、可编辑预设（Hello / OK / AT / AT+GMR）、HEX 模式、定时 / 重复发送。
- **多条发送**：10+ 可编辑行，支持"全部发送"、按间隔循环、HEX 模式、保存 / 载入 JSON、复位。
- **校验和面板**：CRC32 / CRC16 / Sum8 / Sum16 / XOR8 等算法，可设偏移量、追加 / 替换 / 插入模式、大小端、预览。

### 3.2 Modbus 工具（Modbus Tool）

> Modbus RTU/TCP 主机分析仪与从机模拟器。

分为 **主机（Host）** 和 **从机模拟器（Slave Simulator）** 两个标签页。

**主要功能：**

- **协议帧**：支持 **RTU、ASCII、TCP** 三种帧的构造与解析。
- **功能码**：01 读线圈、02 读离散输入、03 读保持寄存器、04 读输入寄存器、05 写单线圈、06 写单寄存器、15 写多线圈、16 写多寄存器。
- **RTU 帧重组**：按 3.5 字符间隔从分段串口数据重组帧，处理 CRC 与 Modbus 异常码。
- **从机模拟器**：内置可响应主机请求的从设备模拟。

### 3.3 I²C 工具（I2C Tool）

> I²C 总线分析仪与从机模拟器（基于 CH347）。

分为 **总线分析仪（主机）** 和 **设备模拟器（从机）** 两个标签页。

**主要功能：**

- **主机模式**：选择 I²C 总线、IO 电压、I²C 速度；7 位从机地址、寄存器地址类型与值、读取长度、写入数据（HEX）；读 / 写操作；SCL 时钟拉伸、延时设置；传输日志。
- **总线扫描**：扫描 1–127 地址，列出应答设备。
- **高级面板**：脚本化命令列表（`R <reg> <len>` 读 / `W <reg> <bytes>` 写 / `# 注释`），可勾选执行指定行、按间隔循环并设置最大次数。
- **从机模拟器**：可模拟存储器（EEPROM/RAM）或 I²C 屏幕（OLED/LCD）；可配置 7 位从机地址、编辑内存内容、复位 / 注入测试数据；屏幕模拟显示写入的 ASCII 内容。

### 3.4 SPI 工具（SPI Tool）

> SPI 总线分析仪与从机模拟器（基于 CH347）。

分为 **SPI 主机分析仪** 和 **SPI 从机模拟器** 两个标签页。

**主要功能：**

- **主机模式**：SPI 模式（CPOL/CPHA）、速率、片选（CS）、数据位、TX 数据（HEX）、读取长度；支持**只写 / 只读 / 全双工**三种传输方式；统一总线传输日志。
- **多步工作流**：可添加 Send / Duplex / CS 高低 / DC 高低 / RST 高低 / 延时等步骤，按"运行选中 / 全部运行 / 循环"执行，并可保存为预设。内置 TLC5615 DAC 呼吸灯等演示预设。
- **从机模拟器**：可模拟 SPI EEPROM（25xx 系列）或虚拟温度传感器；设置 CS 匹配值、编辑 EEPROM 内容、复位 / 注入测试数据。

### 3.5 SPI 点屏工具（SPI Display Tool）

> SPI 显示屏（OLED/TFT）调试工具，支持 TTF 中文渲染。

针对 SPI 屏幕点屏 / bring-up 场景，与 SPI 工具共用同一 CH347 设备。采用**三栏布局**：

- **左栏（硬件参数 + 初始化命令表）**：SPI 模式、频率 / 速度、CS、数据位、位序（MSB/LSB）；手动 Init SPI、硬件复位；可编辑的初始化命令表（cmd / data / delay 行），一键执行初始化序列。
- **中栏（内容编辑标签页）**：
  - **文本**：多行文字（支持中英日韩），TTF 字体渲染（思源黑体）后取模发送。
  - **图片**：拖拽 / 选择图片，按全屏拉伸 / 等比居中 / 平铺三种缩放模式取模发送，可一键清空。
  - **视频**：选择视频（MP4/WEBM 等），按设定帧率逐帧抽帧下发，带播放 / 停止 / 清空与进度显示。
  - **绘制**：在画布上手绘后发送。
- **右栏（LCD 模拟预览 + 日志）**：实时镜像最近一帧到模拟屏幕；分辨率预设（128×32、128×64、128×128、240×240、240×320、320×240、320×480、自定义，高度自动对齐 8 的倍数以满足 SSD1306 page 整除要求）。

**屏幕预设**：内置 "SSD1306 OLED 128×64" 完整初始化序列，并支持把当前命令表另存为用户预设（持久化、可加载 / 删除）。

> 接线约定：DC 接 CH347 的 **GPIO4（IO4）**，RST 接 **GPIO5**。点屏写显存采用 SSD1306 Page Addressing 模式，写入期间不关显示，避免重复发送时闪烁与文字错位。

## 4. 支持的芯片与硬件

- **总线 / 点屏工具桥接芯片**：CH347（CH347T / CH347F 等），通过随附 DLL 驱动。
- **全志 Sunxi SoC（FEL/FES 模式，见第 6 章未开放工具）**：AW1859、AW1882、AW1886、AW1890、AW1903、AW1912、AW1918、AW1922、AW1931。

## 5. USB 后端选项（设置）

面向全志 FEL/FES（EFEX）通信，可在「设置」中切换：

| 选项 | 标识 | 说明 |
| --- | --- | --- |
| WinUSB（厂商驱动） | `winusb` | Windows 原生，Windows 下默认；可能需用 Zadig 安装驱动 |
| LibUSB（社区驱动） | `libusb` | 跨平台，非 Windows 平台默认 |
